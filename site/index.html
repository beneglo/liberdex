The index-free search engine

Search the web. Skip the index. Skip the bill.

Search engines crawl the web and rent you their index by the query. liberdex has no index. It asks a language model where the answer lives, reads those pages itself, and hands you the best of them. Free inside your agent CLI. Open source, and it runs on your machine.

    Does it work

    Measured against the engines that charge.

    Why

    A search engine you can afford to run yourself.

    Nobody had to crawl the web for liberdex to work. The model already knows where things are, and the pages are still there. That takes the expensive part out of search, and most of the bill with it.

    Free where you already pay

    Inside Claude Code, Codex, Cursor and the rest, the host model names the pages and liberdex reads them. No API key, no second subscription, no search credits to top up.

    Cents, not credits

    Everywhere else a small, fast model does the naming. About a dollar per thousand searches through OpenRouter, nothing at all with a model on your own machine. The reading is free either way.

    Whole pages, not snippets

    Results carry passages from the page itself, and the answer at the top is written from those pages and cites them. You see what the model read, not a summary of a summary.

    Runs where you run

    A laptop, a container, a server you own. There is no account. Your queries go to the sites you search and the model you chose; popular questions share the model's page picks, never the question as typed.

    Any language, any script

    German compounds, Chinese and Japanese without spaces, Vietnamese tone marks, addresses spelled without accents. Ask in the language you think in and get pages in it.

    Yours to keep

    Open source under the AGPL. Read it, change it, host it for your team, plug it into claude.ai or ChatGPT as your own connector.

    Install

    One package, three places to put it.

    Python 3.12 or newer. Not on PyPI yet: uvx and pip take it straight from the repository, nothing else to install. The first search fetches two small ranking models, about 130 MB, once.

    Your agent CLI

    One command adds the search and extract tools and the skill that teaches the host to use them well. Run it again later and it changes nothing. Restart the host and search.

    uvx --from git+https://github.com/beneglo/liberdex \
    liberdex install claude-code

    Your browser

    A search page on your own machine. Pick a model in the settings drawer: a key for OpenRouter or any compatible endpoint, a local runtime, or the Claude, Codex, Gemini or OpenCode subscription already installed. Nothing on the page talks to a third party.

    uvx --from git+https://github.com/beneglo/liberdex \
    liberdex serve --open

    Your server

    The same page and a JSON API in one container, ready in seconds. Add keys and allowed origins the day you open the port. Connect claude.ai, Claude Desktop or ChatGPT to it as a custom connector.

    docker run -p 8080:8080 \
  -e OPENROUTER_API_KEY=… \
  ghcr.io/beneglo/liberdex

    Cost

    What a thousand searches cost.

    $0 In your agent CLI

    The host model you already pay for names the pages. liberdex adds no call of its own.

    $0 With a local model

    Ollama, LM Studio, llama.cpp or vLLM on your own hardware. A small model is enough for this job.

    ~$1 With a hosted model

    A fast, cheap model through OpenRouter or your own provider. The fetching and ranking cost nothing.
